🚀 Responsive Scrolling Landing Page
A sleek, one-page landing page built with HTML5, CSS3, and Bootstrap 5. This project focuses on a seamless user experience with smooth navigation and a fully responsive grid system.

[Live Demo ---](https://devsland-web-project-m1o8yroad-palwasha-khans-projects-5703552d.vercel.app/)

✨ Key Features
Smooth Scroll Navigation: Navigate through sections with fluid animations without page refreshes.

Sticky Header: The navbar remains fixed at the top for easy access as users scroll.

Mobile-First Design: Fully responsive layout that adapts perfectly to smartphones, tablets, and desktops.

Modern UI: Clean typography and a minimalist aesthetic powered by Bootstrap’s layout engine.

🛠️ Tech Stack
HTML5: Semantic structure for better SEO and accessibility.

CSS3: Custom styling and smooth transition effects.

Bootstrap 5: Rapid responsive development and pre-built components.
